# Fixing the 404

## Most likely cause

The zip I sent had a wrapper folder inside it. Extracting and committing that
folder puts everything one level too deep:

```
your-repo/
  oralsurgeryassess/        <-- the wrapper
    index.html
    third-molar/
    sedation/
```

Vercel serves the repo root. With no `index.html` there, `/` returns 404, and
`/third-molar/` and `/sedation/` do too — the real files sit at
`/oralsurgeryassess/third-molar/` and so on.

## Check it in ten seconds

Open your repo on github.com. At the top level you should see:

```
index.html   sw.js   vercel.json   third-molar/   sedation/
```

If instead you see a single folder containing those, that is the problem.

## Fix

From the repo root:

```bash
git mv oralsurgeryassess/* .
git mv oralsurgeryassess/.* .        # if there are any dotfiles; ignore errors
rmdir oralsurgeryassess
git add -A
git commit -m "Move site files to repo root"
git push
```

Or simply drag the files up a level in the GitHub web editor and delete the
empty folder. Vercel redeploys on push.

## If the repo root already looked correct

Then it is a project setting rather than file placement.

**Vercel → your project → Settings → Build and Deployment:**

- **Root Directory** — must be empty. If it names a folder, Vercel serves only
  that folder and everything else 404s. This is the usual culprit when a repo
  has been restructured.
- **Framework Preset** — set to `Other`.
- **Build Command** — empty (or "override" left off).
- **Output Directory** — empty. If it is set to `dist`, `build`, or `public`,
  Vercel looks there and finds nothing.

Change any of these, then redeploy: Deployments → latest → ⋯ → Redeploy.

## Confirm which URL fails

If it still 404s, note exactly which of these do and do not work — the pattern
identifies the cause:

| URL | 404 means |
|-----|-----------|
| `/` only | root `index.html` missing or misplaced |
| `/third-molar/` only | folder not committed, or a name/case mismatch |
| everything | Root Directory or Output Directory set in Vercel |
| assets only | `vercel.json` not at the repo root |

Vercel's Deployments tab has a **Source** view showing exactly which files were
deployed. If a file is not listed there, it never reached the build.
